# leonxlnx-stitch-design-taste-skill

> 화면 대신 DESIGN.md 문서 1개 + 금지 패턴 목록으로 다음 화면부터 통제.

## 이 스킬의 역할

AI로 계속 화면을 만들 때마다 같은 취향을 다시 설명하고 있을 때,
이 스킬은 **취향을 문서로 한 번만 남기는 방법**을 알려줍니다.

- 분위기 3다이얼(밀도·비대칭·움직임) + 색 6역할 + 폰트 3종 + 금지 패턴 12항목을 **DESIGN.md** 1개로 정리
- 만든 문서를 Google Stitch에 넣으면 그 문서대로 화면이 생성되고, 없어도 코딩 에이전트 프롬프트로 그대로 사용
- 이모지 ❌, 보라 그라디언트 ❌, 순검정 ❌ 같은 **금지 목록**이 문서에 고정되어 이후 화면에서 반복 실수를 막음

## 누가 쓰면 좋은지

- **비개발 프리랜서**: 매번 "예전처럼 만들어줘"를 다시 설명하는 대신 문서 하나면 될 때
- **클라이언트 보고가 필요한 사람**: "저희 화면은 이 기준대로 됩니다"를 문서로 보여줄 때
- **색·폰트 관리가 힘든 사람**: 디자인 결정을 한 파일에 모아 일관성 유지
